# MAIT user documentation

This folder will hold a copy of the MAIT user documentation. It will be mirrored here automatically from the released docs.

Do not edit files in this folder by hand: manual edits are overwritten by the next sync. To report a mistake in the documentation, open an issue: <https://github.com/mait-sh/mait-sh/issues/new/choose>.

Until the mirror is in place, read the documentation at <https://mait.sh/docs>.
