# MAIT

> [!WARNING]
> **MAIT is in beta.** Features, commands and settings can change or disappear without notice. Agents run commands and handle credentials, so do not use MAIT on machines or data you cannot afford to lose. Read the full [beta notice](NOTICE-BETA.md) before you start.

MAIT gives an AI agent a complete, disposable development environment to work in. On your computer, the AIDCX launcher starts a project container from the MAIT image. Inside it you run the agentic CLI you chose, with development tools and agent tools (MCP servers) already available. The portal at [mait.sh](https://mait.sh) holds your account, features and release channels.

## Platforms

- Linux
- macOS on Apple Silicon
- Windows with WSL 2

Intel Macs are not supported.

## Report a problem or suggest an improvement

Open an issue with one of the forms: <https://github.com/mait-sh/mait-sh/issues/new/choose>

- [Report a problem](https://github.com/mait-sh/mait-sh/issues/new?template=bug.yml)
- [Suggest an improvement](https://github.com/mait-sh/mait-sh/issues/new?template=enhancement.yml)
- [Ask a question](https://github.com/mait-sh/mait-sh/issues/new?template=question.yml)

Do not report security vulnerabilities in public issues. See [SECURITY.md](SECURITY.md). For anything else, see [SUPPORT.md](SUPPORT.md).

## Help us build MAIT

MAIT is at an early stage. We are consolidating, testing and completing features, and we are looking for people to help. In your account on the portal, under Preferences, switch on **I want to support** (feedback, requirements and early testing) and/or **I want to contribute** (access to the code and joining the team). We will contact you when we can.

This repository is where beta users report problems and suggest improvements. The [docs](docs/) folder will hold a copy of the user documentation, mirrored automatically from the released docs. Outside code contributions are not accepted yet; see [CONTRIBUTING.md](CONTRIBUTING.md).
