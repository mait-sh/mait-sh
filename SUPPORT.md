# Support

MAIT is in beta. Everything below is handled on a best-effort basis, and there is no promised response time.

## Where to ask what

| You want to | Go to |
|---|---|
| Report a problem | [Bug report form](https://github.com/mait-sh/mait-sh/issues/new?template=bug.yml) |
| Suggest an improvement | [Enhancement form](https://github.com/mait-sh/mait-sh/issues/new?template=enhancement.yml) |
| Ask a question | [Question form](https://github.com/mait-sh/mait-sh/issues/new?template=question.yml) |
| Report a security vulnerability | Email security@mait.sh privately; see [SECURITY.md](SECURITY.md). Never in a public issue. |
| Anything else | Email support@mait.sh |

## Before you open an issue

- Look in the documentation: <https://mait.sh/docs>, and the troubleshooting guide: <https://mait.sh/docs/troubleshooting>.
- Search the [existing issues](https://github.com/mait-sh/mait-sh/issues?q=is%3Aissue), including closed ones.
- Never post secrets, tokens, private keys or personal data. Review logs and command output before you paste them.

## What happens next

A new issue is labelled `needs-triage` until the MAIT Team looks at it. If we label it `needs-info` and the author does not reply for 7 days, it is closed automatically. When the author replies, the issue reopens and goes back to triage.
